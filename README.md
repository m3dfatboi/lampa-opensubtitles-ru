# OpenSubtitles для Lampa

Плагин добавляет субтитры OpenSubtitles в Lampa. Во внутреннем плеере найденные варианты появляются в штатном меню субтитров рядом со встроенными дорожками, а на Android APK Lampa могут передаваться во внешний плеер при запуске видео.

API key, логин и пароль OpenSubtitles не нужны.

## Источники

Плагин ищет субтитры сразу через два публичных источника:

- Stremio addon `OpenSubtitles v3`: `https://opensubtitles-v3.strem.io`
- `rest.opensubtitles.org`

Результаты объединяются, дубликаты по URL убираются, затем список фильтруется по выбранному языку и сортируется по доступному рейтингу/количеству скачиваний. Ссылки на сами файлы субтитров ведут на `subs5.strem.io`.

## Возможности

- Фильмы и сериалы.
- Поиск по IMDb ID. Если в карточке Lampa есть только TMDB ID, плагин пытается получить IMDb ID через TMDB Lampa.
- Для сериалов используется сезон и серия из данных запуска или имени файла (`S01E03`, `1x03` и похожие варианты).
- В меню субтитров сериала есть пункт **Поиск по другой серии**: можно вручную выбрать сезон и серию, если Lampa определила эпизод неправильно.
- Файл субтитров для внутреннего плеера загружается только после выбора конкретного варианта.
- В Android APK Lampa перед запуском внешнего плеера плагин добавляет найденные субтитры в объект запуска `subtitles`.

## Языки

Доступны 10 языков:

English, Русский, Español, Français, Deutsch, Italiano, Português, Polski, Українська, Türkçe.

Внутри плагин использует ISO 639-2 коды (`eng`, `rus`, `spa` и т.д.), потому что они нужны OpenSubtitles.

## Настройки

После установки появится раздел `Настройки -> OpenSubtitles`.

- **Включить поиск субтитров** — включает или отключает плагин.
- **Язык субтитров** — выбирает язык поиска.
- **Сколько вариантов показывать** — лимит результатов: 5, 10, 15, 25 или 50.
- **Android: передавать во внешние плееры** — включает передачу найденных субтитров во внешние Android-плееры. Включено по умолчанию и не влияет на внутренний плеер.
- **Показывать ошибки поиска** — показывает сетевые ошибки поиска в уведомлениях Lampa.

Отдельной настройки endpoint-ов в интерфейсе сейчас нет: источники заданы в коде плагина.

## Установка

1. Разместите `opensubtitles_ru.js` на HTTPS-хостинге, GitHub Pages или локальном сервере, доступном устройству с Lampa.
2. В Lampa откройте `Настройки -> Расширения -> Добавить плагин`.
3. Укажите URL до `opensubtitles_ru.js`.
4. Откройте `Настройки -> OpenSubtitles` и выберите язык субтитров.

## Внутренний плеер Lampa

Для внутреннего плеера плагин дополняет штатную панель субтитров Lampa. При выборе варианта OpenSubtitles плагин скачивает файл, парсит SRT/VTT и выводит текст через стандартный слой субтитров Lampa.

Если субтитры уже есть в видео или источнике, они остаются в списке. OpenSubtitles добавляются отдельно.

## Внешние Android-плееры

На Android APK Lampa плагин перехватывает запуск `Lampa.Android.openPlayer`, ищет субтитры перед стартом внешнего плеера и добавляет их в `data.subtitles`. Если видео запускается из playlist, субтитры также добавляются в текущий элемент playlist.

Дальше Android APK Lampa сам передает эти данные выбранному плееру через intent. Работоспособность зависит от версии APK Lampa и от того, поддерживает ли конкретный внешний плеер субтитры из intent.

Чтобы запуск видео не зависал, ожидание поиска для внешнего Android-плеера ограничено несколькими секундами. Если за это время субтитры не найдены или источник не ответил, видео запускается без них.

На WebOS, Tizen, iOS, Apple TV, браузерной версии и Media Station X плагин не может напрямую передать субтитры во внешний плеер: там субтитрами управляет сам внешний плеер.

## Диагностика

Откройте консоль Lampa или `chrome://inspect` на Android TV и смотрите логи с префиксом `[OpenSubtitles]`.

В логах видно:

- какая версия плагина загружена;
- какой IMDb ID, сезон и серия используются;
- сколько результатов вернул Stremio addon;
- сколько результатов вернул `rest.opensubtitles.org`;
- сколько субтитров осталось после фильтра по языку;
- были ли субтитры добавлены во внешний Android-запуск.

Если результатов нет, чаще всего причина одна из этих:

- у карточки нет IMDb ID и Lampa не смогла получить его через TMDB;
- для серии не определились сезон или номер эпизода;
- выбранный язык отсутствует у OpenSubtitles;
- устройство не может достучаться до `opensubtitles-v3.strem.io`, `rest.opensubtitles.org` или `subs5.strem.io`;
- внешний Android-плеер не поддерживает переданные через intent субтитры.
